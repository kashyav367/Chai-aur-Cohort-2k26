## 🛠️ Procedure to Follow

1. **Open** the repo link for the lab you want to complete.
2. **Fork** the repo to your own GitHub account.
3. **Clone** your forked repo to your local machine.
4. **Make code changes** and test your code.
5. **Commit** the file changes.
6. **Push** the changes to your forked repo.

> ⚠️ **Do NOT raise a Pull Request.** Make the repo public on GitHub instead.

---

### ✅ Quick Command Reference

```bash
# Clone your fork
git clone https://github.com/<your-username>/<repo-name>.git

# Move into the project folder
cd <repo-name>

# After making changes
git add .
git commit -m "Completed lab exercise"
git push origin main
```
